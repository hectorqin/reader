# 影音设计参考

本目录只保留影音的历史设计基准。早期原型、反复覆盖的截图、失效的构建哈希和逐轮进度记录已移出仓库。

- 当前设计基准是上一级的 [Reader V3 统一原型](../Reader%20V3%20·%20统一设计系统与完整原型.html) 与 [V3 主题语义令牌](../Reader%20V3%20主题语义令牌.md)：统一导航（首页、书架、影音、我的）、手机频道分段切换、我的作为设置中心、媒体库管理与扫描与元数据等页面以它为准。
- [冻结 v2 高保真原型](v2-review/index.html)：早期采用的影音布局参考，包含桌面和手机、主题及状态。原型中的作品 ID、查询参数和状态参数是演示数据；其中的 `/media/:channel/settings/*` 设置页和频道菜单已被 V3 导航与「我的」取代，路由以[导航说明](../../media-navigation.md)为准。

后续验收结果生成到被 Git 忽略的 `artifacts/media`，需要长期保留的截图应人工挑选；不要提交整批重复截图。运行方式见[验证说明](../../media-validation.md)。
