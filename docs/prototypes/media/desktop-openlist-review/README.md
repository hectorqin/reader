# 桌面分类、选择器、收藏与 OpenList 复核

[布局与下拉截图](index.html) · [OpenList 浏览器闭环](../openlist-e2e-review/index.html) · [OpenList 配置说明](../../../media-openlist.md)

## 本次修正

- 桌面分类栏原来的固定父容器容纳不了 tab 的高度与外边距，造成文字、下划线和分隔线错位。改为随内容计算父栏高度，tab 保持 44px，桌面顶部间距 5px、底部间距 16px。
- 影音选择器改为统一主题弹层，覆盖媒体库、版本、季、排序、权限、播放偏好等；支持选中标记、键盘操作、外部点击和 Escape 关闭，靠近视口底部向上展开。Plyr 自带控件不在替换范围。
- 收藏统一到 `#/media/favorites`，旧频道收藏链接继续可用。类型筛选放在弹窗内，`scope` 与分页随 URL 恢复。列表按 v2 使用最大 850px 的居中内容区、紧凑行、计数和筛选入口。
- 新建媒体库增加 OpenList。输入服务地址、远端目录，以及可选令牌和目录密码；创建前验证连接，随后扫描。编辑页面只显示凭据是否已配置，可更新或显式清除，留空保留。

## 视觉核对

生产构建在 390、1120、1308px 下生成 20 张截图。人工检查了桌面分类栏、浅色与深色下拉、收藏列表、新建 OpenList 表单和窄屏向上展开的下拉。图集中分类和收藏附有冻结 v2 原型对照；原型本身未修改。原型中的播放进度、数量和资料仅为示例，实现按可用数据展示。收藏的规范路由按本次需求更新，冻结原型内旧路由文案不代表本次实现。

结构断言验证 tab 高度、按钮边界、下划线、隐藏滚动条、列表居中宽度、菜单视口边界及页面无横向溢出。交互验证旧路由规范化、收藏筛选刷新恢复和选择器关闭。结构断言用于补充图片审查。

## 功能验证与边界

- 前端全量 Vitest 运行通过；新增选择器交互与收藏行为另有定向回归，生产构建通过。
- 后端 OpenList、本地存储、扫描、权限、元数据、迁移和启动隔离相关回归通过。依赖 FFmpeg 的 5 项真实内嵌资源测试因环境未配置而跳过，未记为通过。
- 浏览器闭环使用生产页面、真实 Reader 接口、扫描器与临时 SQLite 数据库；OpenList 上游是本机同契约模拟服务。验证了创建、扫描、实际解码播放、精确 Range 字节读取、凭据保留与轮换，以及下载请求不转发 API 令牌。
- 未连接用户的真实 OpenList 或具体网盘驱动；未进行 Android 真机测试。OpenList 当前使用服务端代理播放，远端文件暂不读取内嵌标签、封面和章节，支持外置资料；不包含转码。
- 阅读页面、书架设置与默认阅读入口保持原有行为。

复跑命令（从 `web` 目录运行，先完成 `npm run build`）：

```powershell
node tools/media-desktop-openlist-review.cjs
node tools/media-openlist-e2e.cjs
```

可通过 `PROTOTYPE_CHROMIUM` 指定本机 Chromium 路径。所有验收服务和数据均为临时实例。
