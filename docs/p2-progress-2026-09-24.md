# P2 交付与验证记录

本轮依据 [需求分析](closed-issues-analysis-2026-09-23.md) F2、F3、G，实现书源质量与插件接入体验，并完成生态互通的独立方案。P0/P1 和其他已有改动保留；未提交、未部署。

## 已交付

1. **换源质量检测**：按所选章节获取并清洗正文，展示字符数、图片数、字节大小、最新章节和检测耗时；候选卡片保留本次检测摘要或错误。不批量预抓所有来源。切换章节或关闭面板会取消检测并忽略迟到结果。
2. **空章保护**：刷新和确认换源时均强制验证，空白/清洗后为空的正文返回 `EMPTY_CHAPTER`；失败不替换当前绑定或已有缓存。质量预览不写正文缓存或修改书籍。图片章允许通过。
3. **个人凭据状态**：增加当前账号的配置状态与最近访问观察，支持删除单项；保存、删除、修改连接配置后重置观察。用 generation 防止旧请求覆盖新凭据状态，不返回凭据值。
4. **插件接入说明**：显示全部已知能力的“已声明/未声明”；站点登录过期、未登录、人工验证三个错误码不会清除 Reader 会话。说明 OPDS 客户端、网站适配、Legado 与宿主边界。
5. **电纸书预设**：一键浅色、分页、无翻页动画，沿用当前设备设置存储，不影响其他设备。不是设备全刷控制。
6. **生态方案**：[OPDS 服务端、WebDAV、进度互通、导出、NAS 与浏览器矩阵](ecosystem-roadmap.zh-CN.md)。这些协议仍需独立实施，本轮没有宣称已提供。

## 边界与后续

质量结果是一次读取快照，不能验证缺段、广告、标题错配或版权授权；确认换源会重新读取。耗时包括目录、正文、内嵌图片处理，不包括 acquire 和客户端网络往返。字符数不含空白和 HTML 标记。

访问状态表示来源实例最近一次请求观察；聚合插件的部分站点错误也会影响状态，不是逐网站会话管理。插件未报告过期时间时不推测，也不提供任意验证链接。人工验证仍需站点/插件实现。

浏览器流程使用受控插件，未对真实付费站点、验证码站点、Safari、Firefox、Android 或电纸书硬件做兼容认证。后续按生态方案单独验收。

## 续批：OPDS 服务端与 WebDAV（2026-09-24）

已新增只读 OPDS 1.2 服务端、个人应用凭据管理界面、独立撤销/到期、账号隔离、分页/搜索/封面/Range 下载。与 Reader 内置 OPDS 客户端完成真实协议对接。

新增管理员 WebDAV 备份 CLI：离线快照验证、流式 ZIP、临时上传重试、远端 SHA-256 校验、MOVE 不覆盖发布、取消和失败清理。未配置用户 WebDAV 地址，因此未向用户外部存储上传；已用受控 HTTP WebDAV fixture 验证并解压校验备份。详见 [接入指南](opds-webdav.zh-CN.md)。

续批验证：Server 全量在 test-concurrency=2 下 344 项（342 通过、2 Windows 跳过），Web 595 项及已有 Node 29 项；类型与生产构建通过。默认高并发服务端运行曾使既有 1 秒插件超时测试失败，降低并发重跑全量通过。浏览器覆盖新 OPDS 凭据创建、仅一次显示、重新打开不回显、撤销后目录返回 401。
