# 书源端到端与 UI/UX 验证

日期：2026-09-21。浏览器：Windows Chrome，headless；生产 Web bundle、真实 Fastify HTTP 服务、SQLite 和独立 Node.js 插件进程。测试创建临时数据目录，运行完清理，不操作现有书库。上游网站由本地 HTTP fixture 提供 45 个书源、小说搜索、详情、目录与富文本正文；没有模拟 reader API。

## 实际发现与修复

| 问题 | 修复后行为 | 证据 |
| --- | --- | --- |
| 新用户注册后立即掉线 | 正确读取注册响应内的 session；页面重载后仍保持登录 | 浏览器注册、重载、管理员安装插件；API 回归 |
| 第 2 页保存规则设置后回到第 1 页，且没有反馈 | 操作携带当前筛选和页码；编辑 JSON 再保存也回原页；明确显示保存结果 | 45 条书源的第 2 页操作 |
| 长列表中 Tab 和反馈滚出视野 | 配置分类与状态提示放在固定工具区；切换分类回到其内容顶部 | 手机长列表截图、控件视口断言 |
| 订阅失败只显示 SUBSCRIPTION_HTTP | 展示中文原因、HTTP 状态和旧规则保留说明；错误使用 alert；恢复成功清除错误 | 上游 HTTP 503 → 200 |
| 修改订阅周期必须手动重填 URL | 每个订阅直接显示可编辑的当前周期，保存时不重新下载或改变暂停状态 | 周期 360 → 60 分钟 |
| 保存其它表单会丢失导入草稿 | 原声明未变化的其它表单保留草稿；服务端改变表单内容时采用新值，避免覆盖规则编辑内容 | 导入草稿 → 添加订阅 → 保存周期 → 返回导入 |
| 删除和移除订阅立即生效 | 插件声明确认文本；通用渲染器提供行内确认/取消 | 取消删除后原规则仍存在；组件测试确认前无 POST |
| 选择器的无障碍名称混入选项文本 | 控件显式使用字段标签；支持键盘 Tab 导航、操作反馈焦点 | 精确 label 浏览器定位、组件焦点断言 |
| 桌面表单占用过多纵向空间 | 插件声明 inline 布局，宽屏横排、窄屏换行；常用按钮至少 44px 高 | 320/390/768/1280px 截图 |
| 创建和打开书源后缺乏下一步提示 | 保存后显示此实例配置入口；编辑/打开时定位到对应表单或搜索区 | 从 UI 创建两个独立来源并进入配置 |

## 端到端覆盖

- 首次注册、登录持久化、通过 UI 安装本地部署的 npm 插件。
- 创建两个自定义来源；一个来源导入订阅，另一个保持空库。
- 无效 JSON 错误提示及输入保留；导入草稿跨 Tab 和其它动作保留。
- 订阅导入、周期修改、失败提示、保留原规则、恢复后更新。
- 长列表分页、分组修改、原始规则编辑、删除确认与取消。
- 分组与指定书源组合搜索，加入书架，真实插件正文渲染，目录选章换源。
- 320px、390px、768px、1280px 无页面水平溢出；深色提示可读；无 pageerror。
- 既有可控故障浏览器脚本继续覆盖换源失败时原正文保持不变。

## 复现

```powershell
$env:CHROME_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm --prefix web run ui:sources
```

单独运行既有故障交互检查（先构建 Web）：

```powershell
node web/tools/ui-review/plugin-extensions.mjs
```

截图写入 docs/ui-review/sources-e2e-*.png；失败时输出当前页面文本及 sources-e2e-failure.png。脚本启动临时端口、临时数据库，并验证清理路径属于系统临时目录后移除。

回归：Web 534 项 Vitest、插件 16 项（含真实 Chromium 和 tarball 独立安装）、服务端协议及来源 API 11 项通过；前后端类型检查/构建通过。

## 范围限制

这是桌面 Chromium 的视口测试，未运行 Android APK 或 iOS 真机，也未逐一认证公网书源站点。定时调度的重启、隔离和暂停行为由现有服务端/插件测试覆盖，本次浏览器脚本未等待 15 分钟的最短实际订阅周期。未进行完整 WCAG 审计。

## 书源主页面层级调整（同日后续）

- 顶部“书源 / 自动追更 / 插件管理”改为真正的 Tab：等宽布局、选中下划线、ARIA Tab 与面板关联；支持左右方向键、Home、End 和键盘焦点提示。普通成员不显示插件管理。
- 来源行默认只显示主要操作“打开”和次要入口“管理”；订阅与规则管理、基本设置、启停集中在行内展开区，一次只展开一个来源。Esc 关闭并返回管理入口。
- 本轮验证：Web 生产构建及相关组件测试 8 项通过；真实服务端端到端脚本和既有故障交互浏览器脚本均通过。补充 320/390/1280px 主页面无横向溢出断言、Tab 键盘切换，以及管理展开截图。没有重复运行上文的全量测试。

## 表单弹窗与搜书分离（同日后续）

- 默认进入“搜书”：选择已启用的来源后展示其搜索筛选、目录和结果。“书源管理”成为单独的管理员 Tab，只负责来源配置；切换两者时保留当前搜索关键词、筛选和结果。暂停、卸载或删除导致来源不可用后，搜索选择器与旧结果同步清理。
- 新增、编辑来源及个人登录凭据改为原生 dialog；背景不可交互，Tab/Shift+Tab 在弹窗内循环，Esc/关闭/取消返回操作入口，保持页面滚动位置。保存期间禁止重复操作或关闭；保存失败在弹窗内展示原因、聚焦提示并保留输入。
- 表单内容独立滚动，标题与操作栏固定。320×568、390×844 和 1280×844 下，保存按钮均位于视口内。配置仍由通用 schema 声明，无插件类型特判。
- 本轮组件测试扩展至 11 项，覆盖凭据不回显、管理与搜索隔离、搜索状态保留、来源暂停、弹窗保存失败/取消/保存/忙碌期间关闭等行为。真实服务端脚本增加新增和编辑弹窗的焦点返回、Esc、焦点循环与滚动位置验证；继续覆盖订阅、搜索、阅读和换源。
