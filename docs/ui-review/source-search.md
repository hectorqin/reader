# 书源搜索反馈与布局验证

前端通过 POST Streamable HTTP 接收 `results` 事件并按 ref 合并结果，收到 `done` 或 `error` 后结束。宿主按不透明游标继续拉取，直到搜索结束、用户停止或达到结果上限。搜索不再依赖前端轮询。来源内部如何组织请求由插件实现。

停止保留已有结果；退出页面、新搜索和停止后的迟到响应不得覆盖当前结果。通用 `CatalogPage.errors` 经过宿主校验，部分成功时折叠错误，没有结果且失败时展开原因。错误和无匹配采用不同空状态。

服务端协议及 API 测试覆盖流式输出、取消、用户隔离、结果上限和错误校验；Web 测试覆盖结果合并、停止、继续、迟到响应和错误反馈。

`node web/tools/ui-review/source-search.mjs` 使用生产 Web 与通用 fixture API，在 Chromium 验证 390/1024/1440/1920px 布局、键盘展开错误及搜索交互。预先构建 Web，可通过 `CHROME_PATH` 指定浏览器。这个测试验证宿主界面，不验证外部服务可用性。
