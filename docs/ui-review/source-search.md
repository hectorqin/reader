# 书源搜索反馈与布局验证

搜索范围、进度、结果数量、失败详情及书籍操作分层展示。桌面筛选横排，关键词输入更宽；小屏筛选自动换行。多源每批按来源实例的 `searchConcurrency` 并发查询（默认 3，范围 1–10），自动继续后续批次并按 ref 合并去重；单源分页仍由用户点击加载。新搜索清除旧结果及游标。

搜索中可随时停止，保留已返回结果，并可从尚未完成的批次继续。声明 `search.cancel` 的插件接收请求级取消通知；宿主立即清理该请求的等待项与超时，忽略迟到响应，不影响其他用户的请求。退出页面、新搜索及停止后的迟到响应均不能覆盖当前结果。

书源管理显示正常、无匹配、失败、未检查状态及最近检查、成功和错误信息；错误记录经过脱敏并持久保存，恢复成功后仍保留最近错误供排查。更新规则或允许域名后旧状态失效。

通用 CatalogPage.errors 由插件提供并经过宿主校验；搜书与换源共用反馈组件。部分成功时折叠错误，失败且没有结果时展开原因，并提示继续下一批或换源。错误不再拼入标题，普通无匹配不显示失败提示。

复现与验证：

- 插件 engine 回归覆盖单引号 POST 参数、无引号键、尾逗号以及拒绝执行表达式；实际 HTTP 404 保留状态码，不暴露请求 URL。
- 插件多源回归覆盖失败隔离、成功结果与游标保留。
- 宿主协议测试覆盖可选错误字段透传和非法字段拒绝。
- Web 测试覆盖部分失败、全部失败、无匹配、详情默认开合及翻页保留查询。
- 真实端到端 `cd server; node --import tsx ../web/tools/ui-review/sources-e2e.mjs` 覆盖 45 个书源批次合并、停止、取消、继续、错误及健康状态刷新，使用真实 HTTP、SQLite、独立 Node 插件和生产 Web。
- 服务端回归覆盖取消单个搜索不影响并发用户，以及插件未确认取消时宿主仍清理超时；Web 回归覆盖去重、停止、忽略迟到响应及继续搜索。
- `node web/tools/ui-review/source-search.mjs` 使用生产 Web bundle 与通用 fixture API，在真实 Chromium 验证 390/1024/1440/1920px 无横向溢出、键盘展开详情和游标翻页。截图为 `source-search-{failed,partial}-<width>.png`。此 UI 测试使用受控响应，公网可用性单独检查。
