# 书架与书库样式优化

日期：2026-09-21。下文记录本轮最终行为。

- 标题与辅助文字统一；书架提供“书库 / 书源”，书库仅向管理员提供“文件管理”。书库浏览页没有上传输入框、上传入口和书架设置按钮。子目录的面包屑单列显示。
- 搜索框统一圆角与高度；空书架隐藏排序栏，刷新移至标题栏。
- 空状态统一为图标、标题、说明和主操作卡片。空书架可去搜书或打开书库；空书库引导管理员前往文件管理，普通成员只显示等待管理员添加书籍的提示。存在未识别文件时管理员可查看文件管理。空库不再显示单独的“0 本”状态栏。
- 上传与新建文件夹仅在管理员文件管理页出现，只读目录隐藏这两个操作。文件行将名称与大小、时间、状态分两行显示，长名称最多显示两行；点击操作菜单不会再触发行本身的打开动作。
- 文件管理返回：子目录回上一级，根目录回书库浏览页；刷新和直达链接也遵循此规则。书架设置 sheet 固定在视口底部，关闭按钮靠右且点击区域为 44px。
- 上传 POST 和写入探测 GET 接口均验证管理员权限；普通成员直接调用返回 403，测试确认拒绝后目录未发生变化。
- 保留搜索、排序、目录导航和有书时的封面网格。

验证：Web 构建、服务端类型检查；相关 Web 组件和路由测试，及服务端上传测试通过。生产 bundle 在 Chromium 中检查 320/390/1280px 空状态、有书、子目录、无搜索结果、只读和深色主题；验证书源、书库、文件管理上传选择器、目录返回、成员直达文件管理的拦截、设置 sheet 关闭按钮位置，以及页面和导航无横向溢出。

浏览器脚本使用可控 API fixture；没有上传实际文件，也未进行 Android/iOS 真机测试。

书架设置吸顶修复：移除滚动区域顶部内边距，并取消首个分组标题的负外边距，避免标题吸顶时露出下方控件。Web 构建及浏览器检查通过；在 320/390/1280px 宽、568px 高的视口实际滚动面板，验证吸顶标题与面板头部无间隙，顶部命中区域始终由标题覆盖。截图为 `collections-shelf-settings-sticky-*.png`。
