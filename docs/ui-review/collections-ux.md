# 书架与书库样式优化

日期：2026-09-21。下文记录本轮最终行为。

- 标题与辅助文字统一；书架提供“书库 / 书源”，书库仅向管理员提供“文件管理”。书库浏览页没有上传输入框、上传入口和书架设置按钮。子目录的面包屑单列显示。
- 搜索框统一圆角与高度；空书架隐藏排序栏，刷新移至标题栏。
- 空状态统一为图标、标题、说明和主操作卡片。空书架可去搜书或打开书库；空书库引导管理员前往文件管理，普通成员只显示等待管理员添加书籍的提示。存在未识别文件时管理员可查看文件管理。空库不再显示单独的“0 本”状态栏。
- 上传与新建文件夹仅在管理员文件管理页出现，只读目录隐藏这两个操作。文件行将名称与大小、时间、状态分两行显示，长名称最多显示两行；点击操作菜单不会再触发行本身的打开动作。
- 文件管理返回：子目录回上一级，根目录回书库浏览页；刷新和直达链接也遵循此规则。书架设置 sheet 固定在视口底部，关闭按钮靠右且点击区域为 44px。
- 上传 POST 和写入探测 GET 接口均验证管理员权限；普通成员直接调用返回 403，测试确认拒绝后目录未发生变化。
- 保留搜索、排序、目录导航和有书时的封面网格。

验证：Web 构建、服务端类型检查；相关 Web 组件和路由测试，及服务端上传测试通过。生产 bundle 在 Chromium 中检查 320/390/1280px 空状态、有书、子目录、无搜索结果、只读和深色主题；验证书源、书库、文件管理上传选择器、目录返回、成员直达文件管理的拦截、设置 sheet 关闭按钮位置，以及页面和导航无横向溢出。

浏览器脚本使用可控 API fixture；没有上传实际文件，也未进行 Android/iOS 真机测试。

电脑端适配（2026-09-21）：从 1024px 起，书架导航与搜索并排，书架、书库、书源和文件管理统一使用最大 80rem 内容宽度与两侧留白。文件操作收至标题右侧，列表采用文件名、元数据、菜单分列布局。书架设置改为右侧 26rem 面板，支持 Esc 关闭并恢复触发按钮焦点；缩窄窗口时恢复底部 sheet。书源及通用插件页面使用紧凑左对齐 tab，标题与正文保持统一宽度。

桌面验证：生产 Web 在 Chromium 中覆盖 1024×768、1366×768、1920×1080；检查书架、书库、文件列表、设置侧栏、键盘焦点、暗色主题和打开面板时跨断点缩放；同时保留 320/390px 手机回归及短视口吸顶断言。34 项书架/书库组件测试通过；真实 HTTP 服务、SQLite、Node 插件的订阅、隔离、筛选搜索、入架、阅读和换源端到端通过。桌面截图为 `collections-*-desktop-*.png`，插件页面截图为 `plugin-config-desktop-*.png`。尚未验证 Firefox、Safari。

阅读页桌面适配：正文采用 52rem 居中纸张区域，顶栏与纸张对齐；底部使用 50rem 悬浮控制条，进度与操作按钮用分隔线区分。纸张外围背景跟随当前主题，浅色、米黄、浅绿和夜间主题均使用主题色。目录使用左侧面板，界面、朗读和设置使用右侧面板，遮罩降低深度以便预览正文。面板支持 Esc 关闭及焦点恢复，聚焦不触发页面滚动。`desktop-reader.mjs` 验证三种桌面尺寸下四个面板、工具栏显隐、正文尺寸/页码/滚动位置不变、翻页模式、夜间主题，以及 1024×420 短窗口的滚轮操作。6 项阅读工具栏组件测试及移动端 `reader-regression.mjs` 全部通过，后者覆盖正文翻页、阅读信息、主题、插图、漫画、PDF 和 320px 面板。截图为 `desktop-reader-*.png`。

宽度回归：书库、书源主页、插件配置页共用 `--collection-measure`。在 1024/1366/1920px 下逐页比较内容容器及标题的左右坐标和宽度，断言相等；同时验证插件配置的嵌套卡片对齐正文边界，避免只有外层变宽而卡片仍受旧限制。

书架设置吸顶修复：移除滚动区域顶部内边距，并取消首个分组标题的负外边距，避免标题吸顶时露出下方控件。Web 构建及浏览器检查通过；在 320/390/1280px 宽、568px 高的视口实际滚动面板，验证吸顶标题与面板头部无间隙，顶部命中区域始终由标题覆盖。截图为 `collections-shelf-settings-sticky-*.png`。
