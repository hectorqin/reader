# 使用手册

[项目首页](../README.md) · [文档中心](README.md) · [安装部署](getting-started.zh-CN.md)

本页介绍安装后的日常使用。部署参数见[配置指南](configuration.zh-CN.md)，协议细节见 [API](api.md)。

## 书架与书库

- **书架**是当前账号的阅读列表，可搜索、排序、调整密度并查看阅读进度。
- **书库**按挂载目录浏览本地书籍，可将书加入书架。
- **文件管理**供管理员检查磁盘目录。挂载可写且目录权限允许时，可上传、改名、移动、删除和新建目录。

从书架移除只改变该账号的书架记录，不删除书文件。文件管理中的删除会修改磁盘，请按界面确认提示操作。书籍的改名或移动按已有身份更新路径，保留阅读记录。

上传 `.zip/.cbz` 时会作为合集解包，保留必要的目录层级。单纯想把 CBZ 作为书籍扫描时，也可以直接把文件放到宿主机书库目录。重名上传支持保留两份、跳过、覆盖或拒绝整批，具体错误语义见 [上传 API](api.md)。

## 支持格式

| 格式 | 日常使用 |
| --- | --- |
| EPUB | 保留出版方排版、内嵌字体、目录、脚注、竖排和振假名等内容 |
| TXT | 自动识别 UTF-8、GB18030、Big5、UTF-16，支持手动切换编码和章节推断 |
| CBZ / ZIP | 按自然顺序展示页面，支持漫画分页 |
| 图片目录 | 将符合条件的图片目录作为漫画书，支持卷结构 |
| PDF | 基础查看，不解析成可重排正文；功能取决于浏览器或设备查看器 |

`.rar/.cbr` 不支持；ZIP64、加密和分卷压缩包不支持。reader 不提供 EPUB、TXT、PDF 之间的通用转换。

## 扫描与元数据

默认每 30 分钟定时扫描、每 60 秒检查变化，管理员可以手动触发扫描。扫描先比较大小和修改时间，再按需计算内容哈希。`.git`、`@eaDir`、`#recycle` 等目录被跳过，符号链接不跟随。

图片目录会结合图片、卷目录和压缩包结构识别。目录中包含其他书籍文件时，不应将这些书吞并为一个漫画目录；目录识别和分页资源规则见[架构](architecture.md)及 [API](api.md)。

书籍身份与内容有关，不直接依赖文件路径。移动或重命名通常保留身份，相同内容副本会合并；修改文件内容可能改变识别结果。

手动元数据覆盖保存在数据库中，优先于书内信息和文件名解析，重新扫描不会覆盖手动值。撤销手动字段后回到提取值。当前没有内置在线元数据抓取服务；远程书源插件与本地书籍元数据处理是不同功能。

## 阅读设置

字号、主题和界面设置按设备保存；阅读进度和笔记随账号同步。

| 设置 | 作用 |
| --- | --- |
| 分页 / 滚动 | 按屏翻页或连续阅读 |
| 字号、行距、页边距、对齐 | 调整正文，部分设置可选择沿用原书 |
| 字体 | 在原字体栈之前加入选定字体 |
| 主题 | 白、米黄、浅绿、夜间 |
| 亮度 | 界面叠加调暗，不等同于修改设备系统亮度 |
| 图片适配 | 固定版式内容完整显示或适宽 |
| 翻页方向 | 漫画等固定版式内容支持左右方向切换 |
| TXT 编码 | 自动识别异常时手动选择 |

点击正文中央可切换工具栏，左右区域翻页；也可使用目录跳转章节。工具栏、目录和设置面板覆盖正文，避免显隐时重新挤压正文布局。电脑端支持方向键、PageUp/PageDown；Android 可通过外壳处理音量翻页。

EPUB 章节按需加载，长书的目录与传输窗口分开处理，跨窗口跳转会先取相应章节。图标为 Lucide SVG，界面布局与交互规范见 [UI 文档](ui.md)。

## 朗读

可使用三种语音来源：Android 系统 `TextToSpeech`、浏览器 `speechSynthesis`，或管理员配置的 HTTP 语音服务。

- 从当前位置或选区开始，按句朗读并高亮。
- 支持上一句、下一句、暂停、继续和停止。
- 可调整语速、选择可用语音；音调等选项由引擎能力决定。
- 可设置章末继续下一章或停止。

没有中文语音时，先检查设备安装的语音包和当前引擎。需要服务端语音时，参照 [HTTP 朗读配置](configuration.zh-CN.md#http-朗读)。

## OPDS 与远程书源

管理员管理来源实例；读者在来源中浏览、搜索、填写自己的凭据并获取书籍。local 和 OPDS 内置，其它来源通过插件提供。一个插件可添加多个来源实例，配置与管理页面从对应实例打开，具体选项由插件声明。

搜书与管理分开。搜索选项由当前来源提供，结果通过 Streamable HTTP 陆续合并；搜索中可手动停止并保留已有结果。

支持章节阅读的来源可刷新目录和配置自动追更。声明换源能力时，目录中会显示换源入口；确认候选和起始章节后切换，保留书籍记录、书架及旧缓存。旧笔记、书签不会自动匹配到新章节。

实例后台任务由服务端执行，关闭网页不影响调度，暂停来源实例会停止其任务。

## 多用户与离线

首个账号是管理员，后续成员默认由管理员创建。每个账号的书架、进度、笔记和高亮独立。阅读界面参数属于当前设备，不随账号覆盖其他设备的设置。

离线时可使用已经缓存的内容，重新连通后同步阅读状态。远程章节当前以已读取章节缓存为主，不保证尚未读取的整本书可离线。停用或卸载插件后已有缓存可能仍可读，获取新内容需要恢复来源。整书预下载、缓存配额和自动淘汰尚未实现。
