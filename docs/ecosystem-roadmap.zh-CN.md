# 互通与客户端覆盖

## 当前互通能力

- OPDS 客户端可浏览、搜索并获取外部目录中的文件书。
- OPDS 服务端向外部阅读器提供只读文件书籍目录；访问使用专用凭据。
- WebDAV 可上传已完成的离线备份包，不同步运行中的数据库，见[接入指南](opds-webdav.zh-CN.md)。
- OpenList 可接入电影、剧集、音乐与有声书目录，由 Reader 扫描外置资料并代理授权播放，见[OpenList 接入](media-openlist.md)。

跨应用阅读进度互通、通用书籍格式转换和影音转码尚未提供。Reader 账号内的阅读及播放进度可在连接同一服务的客户端间继续。

## 客户端与验证范围

Web 可用于桌面及移动浏览器，Android 提供应用外壳与原生媒体播放。浏览器排版、离线存储、编解码和后台行为均依赖运行环境。Chromium 自动化检查不等同于 Firefox、Safari、iOS 或电纸书实机认证；Android 构建也不能替代真机播放验收。

阅读的电纸书预设调整主题、分页及动画，不控制硬件刷新。PWA 安装与缓存要求见 [PWA 指南](pwa.zh-CN.md)，影音测试及真机边界见[影音验证](media-validation.md)。
