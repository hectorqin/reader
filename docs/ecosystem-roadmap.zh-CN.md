# P2 生态互通与客户端覆盖方案

日期：2026-09-24。依据：[关闭 issue 分析](closed-issues-analysis-2026-09-23.md) F、G。

## 当前可使用的能力

- Reader 的 OPDS **客户端**可连接 Calibre 等外部目录，浏览、搜索并获取文件；具体搜索、分页、下载和鉴权取决于目录服务。
- 来源页可查看插件声明的能力。个人凭据仅显示是否配置，以及当前账号最近一次访问的结果；不代表网站会话持续有效。
- 章节换源可按所选章节检测正文、查看最新章节和耗时。字符数和可读性不能证明章节完整、内容正确或站点授权。
- 阅读设置提供电纸书预设：浅色、分页、无翻页动画。设备自行管理刷新率、残影与全刷；这不是原生电纸书客户端。

## 独立交付项目

| 项目 | 首版建议边界 | 关键决策及验收 |
| --- | --- | --- |
| OPDS 服务端 | 只读发布当前账号有权访问的文件书籍；分页、搜索、封面和原文件下载 | 使用可撤销的客户端凭据；不向外泄露文件路径；两个账号互不可见；停用凭据后不能继续获取资源；用 Calibre/至少一个移动客户端验收。章节书暂不发布，待有可下载出版物再接入。 |
| WebDAV 文件备份 | 上传已完成并校验的一致性备份包，复用 P0 备份/恢复流程 | 不直接同步运行中的 SQLite；临时上传后完成发布；断网重试、配额、保留策略、凭据加密；下载后校验并在独立目录恢复。与书籍文件保存任务分离。 |
| Legado 进度互通 | 独立适配器，明确对方版本、备份格式、书籍身份及定位映射 | 先只读导入并预览冲突；书名作者相同不能直接判为同一本；来源变化、缺章、多设备冲突、时间差均有明确策略；无法映射的记录必须可解释且不覆盖本地。 |
| 章节 EPUB 导出 | 将用户有权获取的指定章节快照导出为一个任务产物 | 固定目录版本，包含图片与目录，记录缺章；取消、配额、重复请求与失败重试可控；通过 EPUB 检验工具并在外部阅读器打开。不能用导出来绕过站点访问限制。 |
| NAS 保存 | 为导出产物选择管理员允许的根目录，保存完成后再扫描入库 | 默认不覆盖同名文件；路径限制、空间不足、写入中断清理、并发导出和原子完成；数据库与书籍文件备份分别说明。 |

2026-09-24 续批已实现 OPDS 服务端只读文件书籍及备份包 WebDAV 上传，使用边界见 [接入指南](opds-webdav.zh-CN.md)。进度互通、章节导出与 NAS 保存仍为独立方案，尚未实现。

## 浏览器验收范围

构建目标 `es2020` 仅描述语法，不保证浏览器具备所需 Web API。当前桌面验收使用 Playwright Chromium，具体版本及结果见 [P2 记录](p2-progress-2026-09-24.md)。

| 客户端 | 支持目标 / 验收要求 | 当前证据 |
| --- | --- | --- |
| Chrome / Edge | 当前稳定版与上一稳定版；阅读、登录、换源、下载和 IndexedDB | 自动化 Chromium 验收，不等同于全部 Chrome/Edge 版本实测 |
| Firefox | 当前稳定版与 ESR；特别检查排版、弹窗和离线存储 | 本轮未实机验收 |
| Safari / iOS | 当前与上一主版本；检查后台冻结、存储回收、语音和安全区域 | 本轮未实机验收，暂不承诺具体最低版本 |
| Android WebView | 当前稳定版；应用桥接、文件访问和生命周期另验收 | 本轮未设备验收 |
| 电纸书内置浏览器 | 必须先验证 JS、IndexedDB、Fetch/流、AbortController 与 dialog；使用电纸书预设 | 无实机证据，旧内核可能无法使用 |
| iOS 原生 / Windows ARM 原生 | 根据用户规模另评估；优先验证现有 Web 使用路径 | 未作为本轮开发项目 |

离线应用安装和更新的环境要求参见 [PWA 指南](pwa.zh-CN.md)。设备低动画预设只关闭阅读翻页动画；其他界面动画可配合系统减少动态效果设置，无法代替硬件刷新控制。
