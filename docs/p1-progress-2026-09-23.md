# P1 实施与验证记录（2026-09-23）

本次实现原需求分析 D/E/F 的阅读工具主流程，并补充万本索引的查询基线。改动保留在工作区，未提交、未部署。

## 已实现

| 能力 | 交付行为 |
| --- | --- |
| 书内检索 | EPUB/TXT/远程章节逐章搜索、摘要、200 条上限、取消、命中高亮、返回原阅读位置；不对图片或扫描 PDF 做 OCR |
| 批注 | 正文选区高亮、批注、书签、编辑、删除、回正文；沿用现有离线同步和墓碑机制；修复同 ID 笔记跨账号覆盖 |
| EPUB 目录 | Web/服务端解析有序 nav/NCX 树，保留层级、fragment、spine，支持折叠和章内定位 |
| 个人纠错 | 精确文字替换、选区过滤、移除及撤销；按账号/书籍保存在 DATA_DIR/reader.db，版本冲突返回 409；不改原书 |
| TXT 目录 | 中文、英文、方括号模板和自定义标题前缀；预览后应用，规则持久化并可撤销 |
| 设备离线 | TXT/远程章节范围下载；EPUB/PDF/CBZ 整文件下载，保留 EPUB 内部资源；暂停、继续、取消；失败可重试并跳过完成资源 |
| 缓存管理 | 服务地址与账号隔离；默认 256 MiB 配额、实际资源字节占用、按书清理；配额写入串行，失败回滚旧资源 |
| 朗读诊断 | 当前引擎试听；HTTP 实际合成检测，分别报告配置、鉴权、响应体超时、非音频、空音频；停止和关面板释放试听 |
| 大书库基线 | 10,000 条索引的首尾分页、搜索、增量同步验证，单次查询按页返回 |

主要实现位于 web/src/ui/reading-tools.tsx、text-anchor.ts、reading-overrides.ts、core/offline-download.ts、store/publications.ts，以及 server/src/services/reading-overrides.ts 和对应路由。

- Web Node 测试：29 项通过。
- 服务端全量：338 项，336 通过、2 项 Windows 环境跳过；最后的覆盖层参数校验和万本测试再次通过。

## 明确边界

- 本轮完成的是上述可用流程；真实 iOS/Android、HTTPS 反代、后台音频和跨真机恢复尚待实机验收。
- 未做磁盘上万本真实书籍的全量/增量扫描压测；内存索引基线不能替代该验收。
- TXT 自定义规则是有界标题前缀匹配，不支持任意正则或跨书自动套用的规则库；变更章节结构后从首章打开，旧定位可能失效。
- 纠错规则联网保存，已缓存规则离线应用；其他设备下次打开书籍拉取，不通过进度同步接口实时推送。空替换只过滤选区，未实现全书正则过滤。
- 下载任务关闭面板即暂停。整文件下载重试从头请求；章节下载按已完成资源续传。图片目录不支持整书预下载。
- 配额统计是新账号作用域下的正文/整文件缓存，未包含封面、服务端缓存和旧版本非账号隔离缓存；不自动淘汰。
- 浏览器缓存可能被系统回收；未缓存的章节仍需联网。正文版本变化、目录重排或换源后的旧笔记不会强行匹配到不确定文本。
- Docker 引擎未启动，本轮未做容器和实际部署验收。
