# 业务配置

管理员在「系统设置 → 服务配置」编辑实例业务配置；「影音设置 → 元数据刮削」同时提供 TMDB、MusicBrainz 的直接入口。普通用户无法读取或修改服务凭据。

| 分类 | 可修改内容 |
| --- | --- |
| TMDB | 启用、读取令牌、API Key、元数据语言，令牌优先于 API Key |
| MusicBrainz | 启用、应用标识与联系地址，例如 `Reader/0.1 (mailto:admin@example.com)` |
| HTTP 朗读 | 启用、合成接口、Bearer 令牌、音色列表接口、超时、缓存上限，支持检测连接、获取音色、试听和清理缓存 |
| 扫描 | 阅读书库检查间隔（0 关闭）、同时扫描的媒体库数、远端文件处理并发数 |
| 刮削高级设置 | 请求超时、失败重试次数；MusicBrainz 的服务商限流仍强制执行 |
| 登录与服务访问 | 对外地址、允许的浏览器来源、访问令牌与登录续期有效期 |
| WebDAV 备份 | HTTPS 目录、账号、密码、上传上限、连接测试及已验证离线备份上传 |

注册策略仍在「注册与邀请」管理；OpenList、媒体库目录及权限沿用原管理页面。个人音色、语速和阅读样式不属于实例配置。

## 保存与生效

- 配置存入 `reader.db`，随完整 DATA_DIR 备份与恢复。备份含凭据，需限制访问权限。
- 凭据不回显。未编辑时保留，填写时替换，点击清除后保存会删除；关闭功能可以保留凭据。
- 保存后新请求使用新配置；已开始的朗读请求、扫描文件处理及批量刮削使用原配置。媒体库同时运行数量的调整在队列调度时应用。
- 阅读自动扫描合并为一个定时器；保存后重新计时，不重复触发两套相同扫描。启动时仍进行一次书库检查。
- 登录有效期调整只影响随后签发的令牌，不修改已经签发的令牌。OPDS 的对外地址立即更新。
- 连接测试与试听使用当前表单，成功不代表已经保存。重新加载会丢弃未保存编辑。
- 同一分类使用版本号防止覆盖其他管理员的修改；遇到冲突需重新加载后编辑。

## 旧配置迁移

升级首次初始化每个分类时，导入原有 `MEDIA_TMDB_*`、`MEDIA_MUSICBRAINZ_USER_AGENT`、`TTS_*`、`PUBLIC_URL`、`CORS_ORIGINS`、登录有效期及 `WEBDAV_*` 环境变量。原 `SCAN_INTERVAL` 与 `WATCH_INTERVAL` 取启用值中的较小间隔，两者都关闭则关闭自动检查。已有注册策略优先于 `ALLOW_REGISTRATION`。

完成初始化后，环境变量不再覆盖已保存配置，清空凭据也不会让旧变量重新生效。部署端可移除这些业务环境变量。监听端口、DATA_DIR、BOOKS_DIR、WEB_DIR、签名密钥、日志级别和外部程序路径仍是部署参数。

## WebDAV 备份

这里配置备份目的地，不提供在线数据库快照。先按[离线备份指南](backup.zh-CN.md)停服制作完整、已验证的备份，再启动服务，从 WebDAV 页输入服务器可访问的备份目录及 `.zip` 文件名上传。容器中只能访问已挂载的目录。

上传先验证本地清单，临时上传后校验远端内容，再发布最终文件；不会覆盖同名备份。连接测试使用 `PROPFIND` 检查目录访问，不保证上传配额或写权限。

命令行仍可用 `node dist/maintenance/webdav-cli.js <备份目录> <名称.zip>`，读取 DATA_DIR 对应实例已保存的 WebDAV 配置，不再从环境变量读取目的地凭据。
