# 影音使用说明

影音支持电影、剧集、音乐和有声书。默认启动仍进入书架；从书架的「影音」入口进入，也可直接访问影音链接。手机点击顶部频道名称切换，桌面使用频道导航；「阅读」返回书架，阅读界面与书架设置保持原位。

## 新建与管理媒体库

管理员进入「影音设置 → 媒体库管理 → 新建媒体库」，选择内容类型、接入方式和访问范围。普通用户只看到已获授权的媒体库。

- **服务器目录**：填写 Reader 服务端能读取的路径。Docker 部署填写容器内路径，例如将宿主目录只读挂载到 /media/music 后，填 /media/music。
- **OpenList**：填写服务地址、远端绝对目录，以及可选访问令牌和目录密码。创建前验证连接。编辑已有库可更新或清除凭据；不改服务地址和根目录。见[OpenList 接入说明](media-openlist.md)。

创建后自动提交扫描。若创建已成功而扫描失败，查看该库任务并重试扫描，不必再次建库。创建请求响应丢失时，在原表单保持配置不变重试可恢复同次创建；刷新或修改配置后，先核对是否已有目标库。

扫描只读源文件，不移动、改名或写回标签。目录或远端读取失败会保留已发布目录和资料。缺失文件可在详情查看状态；恢复文件后重扫。不同播放版本需要明确选择，不能按文件名推断为同一版。

## 资料、刮削和整理

本地库优先读取文件标签、NFO 和同目录封面；ffprobe 用于编码、时长及章节探测，ffmpeg 用于部分内嵌资源提取，两者不等于转码功能。OpenList 支持外置 NFO、封面、歌词和字幕，暂不读取远端内嵌标签、封面及章节。

服务器可配置 MEDIA_TMDB_TOKEN 或 MEDIA_TMDB_API_KEY（同时配置时优先令牌），以及 MEDIA_MUSICBRAINZ_USER_AGENT。管理员在作品菜单中匹配资料，审阅候选后确认；也可在「扫描与刮削」中发起批量任务并重试未完成项。来源网络、凭据或封面下载失败会单独提示。

详情的资源信息菜单可查看文件与技术信息、管理版本。手工资料、作品归属、版本拆分或合并会在重扫时保留，不修改原文件。移动版本不转移收藏，也不复制原作品的人工资料；更改剧集、季和单集关系后需重新确认受影响的在线匹配。

## 浏览、搜索与收藏

媒体库筛选位于列表左侧，排序等操作在右侧。演播者目录同样支持媒体库筛选。全局搜索支持频道和内容类型，权限及分页在服务端生效。

收藏统一使用 #/media/favorites，无频道 tab。右侧筛选选择内容类型，筛选和分页写入地址，刷新后可恢复。歌手、专辑、剧集和有声书分别进入自己的详情路由；返回使用实际来源页面。

## 播放与恢复

视频由 Plyr 提供内置控件；音频页面提供封面、进度、队列、歌词、倍速和睡眠定时。关闭迷你播放器停止当前播放。章节和曲目按当前版本的真实顺序处理，失效资源不会悄悄切到其他版本。

播放器地址包含作品 ID 和播放部分 ID，刷新后重新读取会话与授权。服务器保存播放进度；权限被撤销、资源失效或会话冲突时需要按页面提示处理。浏览器自动播放限制可能要求再次点击播放。

Android 原生后台播放与条件恢复见[后台播放说明](media-background-auth.md)。恢复保持暂停，不以旧快照覆盖另一设备的进度。

## 部署、备份与限制

影音数据使用 DATA_DIR/media.db，阅读和账号使用 reader.db。停服备份完整数据目录，成对恢复数据库及签名密钥，见[备份恢复](backup.zh-CN.md)。影音异步启动，阅读健康检查成功不代表影音已就绪；MEDIA_STARTING 表示准备中，MEDIA_UNAVAILABLE 需要检查日志。

当前不包含 TVBox/JAR、转码、影音离线下载或云盘账号登录。OpenList 负责其挂载驱动访问，Reader 服务端必须能访问 OpenList 及下载源；某些驱动需要启用 OpenList Web 代理。实际可播放编码取决于浏览器或设备。
